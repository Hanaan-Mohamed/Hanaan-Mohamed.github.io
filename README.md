## 🚀 How to Run Locally on Your Laptop

### Method 1: Direct Browser Launch (Fastest)
1. Open File Explorer and navigate to:
   ```text
   C:\xamppp\htdocs\hanaan portfolio1
   ```
2. Double-click **`index.html`** or right-click `index.html` → **Open with** → **Google Chrome** (or Edge / Firefox / Brave).
3. The portfolio will immediately open in your browser!

### Method 2: Via XAMPP Localhost (Since it's in `htdocs`)
1. Open the **XAMPP Control Panel**.
2. Click **Start** next to the **Apache** module.
3. Open any browser and visit:
   ```text
   http://localhost/hanaan%20portfolio1/
   ```

## 🌐 How to Deploy Online for Free

### Option A: Free Deployment with GitHub Pages

1. **Create a GitHub account** at [github.com](https://github.com) (if you haven't already).
2. Click **New Repository**:
   - Repository name: `hanaan-portfolio` (or `yourusername.github.io`).
   - Set visibility to **Public**.
   - Click **Create repository**.
3. **Upload your files**:
   - In your new repository page, click **"uploading an existing file"**.
   - Drag and drop `index.html`, `style.css`, `script.js`, and the entire `assets` folder (containing `assets/images/profile.jpg`).
   - Click **Commit changes**.
4. **Enable GitHub Pages**:
   - Go to your repository **Settings** tab.
   - On the left sidebar, click **Pages**.
   - Under **Build and deployment** → **Branch**, select `main` (or `master`) and folder `/ (root)`.
   - Click **Save**.
5. Within 1–2 minutes, GitHub will give you a live link like:
   `https://<your-username>.github.io/hanaan-portfolio/`

---

### Option B: Free Deployment with Netlify (Drag & Drop in 30 Seconds)

1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Sign in or sign up with your email or GitHub account for free.
3. Drag the entire `hanaan portfolio1` folder into the Netlify Drop area.
4. Netlify will deploy your website instantly and generate a free live URL (e.g., `https://hanaan-portfolio.netlify.app`).
